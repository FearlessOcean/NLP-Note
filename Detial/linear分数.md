`linear` 的输出是：

**对词表中每个词的打分（logits）。**

也就是这句：

```python
output = self.linear(last_hidden_size)   # [batch_size, vocab_size]
```

如果：

- `batch_size = 32`
    
- `vocab_size = 10000`
    

那么输出形状就是：

```python
[32, 10000]
```

含义是：

- 32 条样本
    
- 每条样本都会得到一个长度为 10000 的向量
    
- 这 10000 个数分别对应词表里 10000 个词的分数
    

比如某一条样本输出：

```python
[1.2, -0.5, 3.8, 0.7, ...]
```

表示模型认为：

- 第 0 个词得分 1.2
    
- 第 1 个词得分 -0.5
    
- 第 2 个词得分 3.8
    
- ...
    

**分数最高的那个词，就是模型最倾向预测的词。**

---

### 它不是概率

这些值通常叫 **logits**，还不是概率。

如果你手动做：

```python
prob = torch.softmax(output, dim=1)
```

才会变成概率分布。

但训练时如果用的是：

```python
nn.CrossEntropyLoss()
```

那就**不要自己先 softmax**，因为它内部会处理。

---

### 结合你的模型

你的模型更像是在做：

**根据前面的序列，预测下一个词是谁。**

所以 `linear` 输出的意思就是：

> “对于词表里的每个词，下一个词是它的可能性有多大。”

---

### 一句话

**linear 输出的是每个类别/词的原始分数，形状是 `[batch_size, vocab_size]`，本质上是在做多分类。**

你下一句可以接着问：  
**“那 target 应该长什么样，才能和这个 output 对上？”**
